# SBR ERP — Cloud Version

## Deploy to Netlify (5 minutes)

1. Go to https://github.com and create a free account
2. Create a new repository called `sbr-erp`
3. Upload all files from this folder to the repository
4. Go to https://netlify.com and sign up with GitHub
5. Click "Add new site" → "Import from GitHub" → select `sbr-erp`
6. Click Deploy — your site will be live at `https://sbr-erp.netlify.app`
